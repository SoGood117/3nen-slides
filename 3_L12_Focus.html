Lesson 12:
In Order to Live a Happy Life

Focus & Try（仮定法）

Focus 1

「〜ならよいのに」　I wish を用いた文

I wish I were happy.

幸せだったらよいのになあ。

I wish を用いて、現在の事実に反していたり、実現の可能性が低かったりする願望を表します。be動詞は主語に関わらず were を使うのがふつうです。
＜ I wish ＋ 主語 ＋ 動詞〔助動詞〕の過去形 〜 ＞　→「〜ならよいのに」

Focus 2

「もし（今）〜ならば，…するだろうに」　仮定法過去

What would life be if we had no courage to attempt anything?

もし私たちが何でもやってみる勇気を持っていなければ、人生はどうなってしまうでしょう。

動詞の過去形や would などを用いて、現在の事実とは異なる仮定や、可能性が低いことを表します。
＜ If ＋ 主語 ＋ 動詞の過去形 〜, 主語 ＋ would〔could, might〕＋ 動詞の原形 … ＞
→「もし（今）〜ならば，…するだろうに」

Focus 3

「もし（そのとき）〜だったならば，…しただろうに」　仮定法過去完了

If I had practiced soccer more, I could have become a J. Leaguer.

もしサッカーをもっと練習していたならば、私はJリーグの選手になれたでしょう。

had ＋ 過去分詞や would などを用いて、過去の事実とは異なる仮定や、可能性が低かったことを表します。
＜ If ＋ 主語 ＋ had ＋ 過去分詞 〜, 主語 ＋ would〔could, might〕＋ have ＋ 過去分詞 … ＞
→「もし（そのとき）〜だったならば，…しただろうに」

Try 1

日本語に合うように、（　）内の語を適切な形に変えましょう。

① If I ( know → knew ) how to use the internet, I would start a blog.

もしインターネットの使い方を知っていたら、ブログを始めるのに。

② I wish people all over the world ( can → could ) see my blog.

世界中の人々が私のブログを見てくれたらよいのになあ。

③ If I ( learn → had learned ) more about computers before, my life ( be → would have been ) much different.

もし以前もっとコンピュータについて学んでいたら、私の人生もずいぶん変わっていたでしょう。

Try 2

日本語に合うように、最も適する語を下から選び、（　）に入れましょう。

achieve/philosopher/courage/curiosity

① Yuri has a strong ( curiosity ) about everything.

ユリは何に対しても強い好奇心を持っています。

② She always tells us that we need ( courage ) and patience to ( achieve ) something great.

彼女はいつも、大きなことを成し遂げるには勇気と忍耐が必要だと私たちに言います。

③ We call Yuri a little ( philosopher ).

私たちはユリを小さな哲学者と呼んでいます。

Try 3

日本語に合うように、（　）内の語を並べかえましょう。

① Everyone has ( to / the / live / right ) happily.

→ Everyone has the right to live happily.

誰もが幸せに生きる権利を持っています。

② If I ( more / had / studied ), I could have passed the exam.

→ If I had studied more, I could have passed the exam.

もしもっと勉強していたら、私は試験に合格できたでしょう。

③ I ( I / wish / were ) a bird.

→ I wish I were a bird.

私が鳥だったらよいのになあ。
